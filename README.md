# Immutable GeoJSON

A safer way to manipulate geography on the web…

Implements [RFC 7946](https://www.rfc-editor.org/rfc/rfc7946).

## Why?

Addresses [a shortcoming](https://github.com/DefinitelyTyped/DefinitelyTyped/pull/71678) of `@types/geojson`.

## What?

Stricter variants of all the base GeoJSON types.
